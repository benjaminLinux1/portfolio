# VU QUANG HUY — Portfolio

Static portfolio prepared for GitHub Pages.

## Publish
1. Create a new public GitHub repository (example: `portfolio`).
2. Upload everything in this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will give you a public URL such as:
   `https://YOUR-USERNAME.github.io/portfolio/`

The site is plain HTML/CSS/JS and needs no build command.
